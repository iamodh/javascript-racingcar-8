# javascript-racingcar-precourse

## 1차 기능 목록

- [x] 입력을 받아 유효성 검사를 진행하고, 자동차 이름들(carNames)과 횟수(trialNumber)를 출력한다.

- [x] 횟수만큼 자동차 경주를 진행하고, 가장 이동을 많이 한 자동차를 우승자 배열에 추가한다.

- [x] 출력 요구사항에 맞추어 차수별 실행 결과와 우승자 안내 문구를 출력하여 테스트를 통과한다.

## 1차 리팩토링 목록

- [x] 유저 인풋 처리 Input 클래스 분리

- [x] 게임 진행 관련 코드 함수 분리

- [ ] 게임 진행 Game 클래스 분리

# javascript-racingcar-precourse

## 1차 기능 목록

- [x] 입력을 받아 유효성 검사를 진행하고, 자동차 이름들(carNames)과 횟수(trialNumber)를 출력한다.

- [x] 횟수만큼 자동차 경주를 진행하고, 가장 이동을 많이 한 자동차를 우승자 배열에 추가한다.

- [x] 출력 요구사항에 맞추어 차수별 실행 결과와 우승자 안내 문구를 출력하여 테스트를 통과한다.

## 1차 리팩토링 목록

- [x] 유저 인풋 처리 Input 클래스 분리

- [x] 게임 진행 관련 코드 함수 분리

- [x] 게임 진행 Game 클래스 분리

- [x] 게임 진행 Game 클래스에서 Car 클래스 분리

## 2차 기능 목록

- [x] 자동차 이름 입력 유효성 검사 추가(공백 입력, 너무 많은 개수의 자동차 이름 입력)

- [x] 시도 횟수 입력 유효성 검사 추가(공백 입력, 음수 또는 0 입력, 너무 큰 숫자 입력)

- [x] 단위 테스트 작성

## 2차 리팩토링 목록

- [x] Game 클래스에서 Console 의존성 제거

- [x] 출력을 담당하는 Output 클래스 생성

- [ ] 에러 상수화, 커스텀 에러 사용
